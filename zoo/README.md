# Лапа — зоомагазин (AZ / RU / EN)

Демо-копия для портфолио: многоязычный сайт-визитка и каталог кормов
и товаров для кошек и собак. Название магазина и логотип вымышленные,
контакты убраны. В каталоге остались фото и названия товаров.

## Страницы

- **`index.html`** — главная: первый экран со сменой фото, блок «шерсть»,
  линейки, категории, калькулятор кормления, вкладки «Ценности / История /
  Послы / Вопросы», «О бренде» с фото до/после, «Качество», «Где купить»
  и форма обратной связи.
- **`products.html`** — каталог: липкая панель брендов и фильтров
  (Все / Для кошек / Для собак / Малыши), поиск, карточки товаров.

## Как устроено

Чистый HTML, CSS и JavaScript, без сборки. Языки переключаются в шапке,
выбор запоминается в браузере. Тексты интерфейса — `js/translations.js`
и `js/home.js`, каталог — `js/translations.js`, `js/catalog.js`,
`js/np-official.js`.
