# Мы вдвоём — сайт для пары на расстоянии

Демо-копия для портфолио. Имена заменены на «Первый» и «Вторая», общий чат
отключён: сайт работает в локальном режиме, и всё, что вы напишете,
остаётся только в вашем браузере.

## Что внутри

- **Главная** — приветствие по времени суток, часы и погода в двух городах,
  обратный отсчёт до встречи, посадочный талон, настроение, «сто причин»,
  вопросы для двоих, колесо свиданий, скретч-карточки.
- **Чат** — сообщения, ответы, реакции, статус «на сайте».
- **История** — лента моментов, фото, список желаний «когда встретимся».
- **Письма** — письма с отложенным открытием.
- **Игры** и **шахматы** на двоих.
- **Квест** (`quest.html`) — поймать ключ и открыть конверт.

## Как устроено

Чистый HTML, CSS и JavaScript, без сборки. Все тексты и настройки —
в `assets/js/config.js`. Если заполнить там блок `firebase`, сайт
переключится на общую базу (Firebase Realtime Database), и оба человека
будут видеть одно и то же в реальном времени.
